Tejuu's birthday site

Pages, in order:
  index.html     passcode lock (code: 1310, set in index.html)
  ask.html       "I made something for you" Yes / No
  good.html      "That's my girl"
  birthday.html  Happy Birthday
  items.html     camera / envelope / cassette
    memories.html, letter.html, song.html
  hug.html       virtual hug

1. Add photos and the song to the assets folder (see the note inside it).
2. Edit your letter in letter.html, captions in memories.html,
   and the song title/artist in song.html (search for the [brackets]).
3. Open index.html in a browser to test.
4. Deploy on Vercel: go to vercel.com > Add New > Project, and drag this
   whole folder in (or push it to GitHub and import the repo).
   No build settings needed; it is a plain static site.
